# LightFieldStudio v0.1.0

First public release of the official SSAT implementation.

- Quality and Performance profiles of the ES+LT light-field reconstruction pipeline.
- Interactive Studio, Vision JSON scene loading, camera controls, calibration and native display selection.
- Bundled Coffee, CBox and SpaceShip with 2K, 4K and 8K display presets. The portable package opens all three scenes offline.
- Windows 10/11 x64 and an RTX 20-series or newer NVIDIA GPU with a compatible driver.

## Run

Download `LightFieldStudio-v0.1.0-win-x64.zip`, verify the SHA-256, extract the whole directory and run `LightFieldStudio.exe`. No separate CUDA Toolkit, Python or Visual Studio installation is required. First launch compiles shaders.

The package is unsigned. Windows may show an unknown-publisher warning. Calibrate the output for your physical LFD; windowed output is a scaled preview.

See the README for source builds, component licenses and the roadmap.
